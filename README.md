# Sales Dashboard - Power BI Project

## Overview

This project is an interactive Sales Dashboard built using Microsoft Power BI. The dashboard provides insights into sales performance, profit trends, customer behavior, and product category analysis. It helps stakeholders make data-driven business decisions by visualizing key performance indicators (KPIs) in an easy-to-understand format.

## Objectives

* Monitor overall sales performance.
* Analyze profit and revenue trends.
* Identify top-performing products and categories.
* Track customer purchasing patterns.
* Support business decision-making through data visualization.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling

## Key Features

* Interactive filters and slicers
* Sales and profit analysis
* Category-wise performance tracking
* Customer insights
* Regional sales comparison
* Dynamic KPI cards
* Trend analysis with charts and graphs

## Dashboard Metrics

The dashboard includes:

* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Category Performance
* Monthly Sales Trends
* Customer Analysis

## Project Workflow

1. Data Collection
2. Data Cleaning and Transformation
3. Data Modeling
4. DAX Calculations
5. Dashboard Design
6. Data Visualization and Insights

## Business Insights

* Identify the most profitable product categories.
* Discover high-performing regions and customers.
* Monitor monthly sales growth.
* Detect areas requiring business improvement.
